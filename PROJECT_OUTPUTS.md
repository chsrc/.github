# SKACH project outputs outside chsrc

Most SKACH repositories live in the [chsrc organization](https://github.com/chsrc). This file lists project repositories that are kept elsewhere, for example in a personal or institutional account, so that every project output can be found from one place.

## How to add a repository

Add a row to the table below by editing this file and opening a pull request, or send the details to the chsrc org owners and they will add it.

Please make sure the repository is public, or at least accessible to the consortium.
