# Contributing to chsrc repositories

Thank you for contributing! This default guide applies to every SKACH/CHSRC repository that doesn't have its own `CONTRIBUTING.md`.

## For consortium members

- New SKACH project repositories go in the chsrc organization. See the [Repository Policy](https://github.com/chsrc/.github/blob/main/REPOSITORY_POLICY.md).
- Start a new repository from the [templates](https://github.com/chsrc/.github/tree/main/templates): README, `CITATION.cff` and licence guidance.
- Make a GitHub release for any version used in a paper, deliverable or demo, so Zenodo can archive it with a DOI.

## For everyone

- Open an issue to report a bug or suggest a change.
- For code changes, fork the repository, work on a branch and open a pull request describing what changed and why.
- Never commit passwords, tokens, personal data or large raw data files.

If you accidentally committed something sensitive, contact the CHSRC org admins via the SKACH slack straight away rather than only deleting the file.
