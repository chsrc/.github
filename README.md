# ska-ch `.github` repository

This special repository holds organization-wide files for the SKACH GitHub organization, ska-ch. GitHub treats a repository named `.github` differently from others.

| Path | What GitHub does with it |
| --- | --- |
| `profile/README.md` | Shown on the ska-ch organization's front page (public repo required). |
| `CONTRIBUTING.md` | Used as the default contributing guide for any ska-ch repo without its own. |
| `REPOSITORY_POLICY.md` | The consortium's repository policy. Not special to GitHub; it just lives here. |
| `PROJECT_OUTPUTS.md` | List of SKACH project repositories kept outside the ska-ch organization. Not special to GitHub. |
| `templates/` | Starter files to copy into new repos: README, `CITATION.cff`, licence guide. Not applied automatically. |

We keep this repository **public**, so the organization profile will show.
