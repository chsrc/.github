# Choosing a licence

You don't need to copy a licence text from here. When you create a repository on GitHub, pick a licence from the "Add a license" menu, or add a file named `LICENSE` and use GitHub's licence picker.

| Content | Suggested licence | SPDX id |
| --- | --- | --- |
| Code | MIT (short, permissive) or Apache-2.0 (permissive, with a patent clause) | `MIT` / `Apache-2.0` |
| Documentation, figures, slides | Creative Commons Attribution 4.0 | `CC-BY-4.0` |
| Data | Creative Commons Attribution 4.0 (or CC0 for public-domain release) | `CC-BY-4.0` / `CC0-1.0` |

Check your partner or institutional agreement first: some institutions require a specific licence, or approval before releasing code.

Use the SPDX id in `CITATION.cff` (`license:`) so the licence is machine-readable.

More help: https://choosealicense.com
